# Where Knowledge Blossoms
### CSEA Saraswathi Pooja Celebration Website
**PSG College of Technology**

An interactive, cinematic, single-page celebration website created for the Computer Science and Engineering Association (CSEA) at PSG College of Technology to commemorate Saraswathi Pooja.

> *"Learn with curiosity. Grow with gratitude. Dream with courage."*

---

## Features

- **Living Canvas Hero**: 40-frame fluid canvas animation of traditional courtyard artwork with ambient flickering brass lamps, wafting incense, and falling flower petals.
- **Floating Petal Breeze**: Subtle, lightweight SVG flower petals drifting across the screen with natural horizontal sway.
- **Refined Editorial Design**: Warm ivory, deep emerald, and antique gold aesthetic with Google Fonts (*Cormorant Garamond* and *Plus Jakarta Sans*).
- **Interactive Brass Diya**: Tap "Discover a Thought" to receive inspiring reflections on curiosity, perseverance, community, creativity, and empathy.
- **Full Story Progression**:
  - **The Celebration**: Introducing the cherished tradition and symbols.
  - **Wisdom & Knowledge**: Reflections on humility and genuine understanding.
  - **Study, Explore, Create**: Connecting learning and computer science.
  - **Gratitude & Togetherness**: Appreciating mentors, families, peers, and community.
  - **Dreams & Possibilities**: Imaginative campus scene with `LEARN → GROW → CREATE`.
  - **Warm Wishes**: Thoughtful festival greetings and official CSEA signature.
- **Accessibility & Performance**:
  - Respects `prefers-reduced-motion` settings.
  - Zero layout shifts with optimized asset loading.
  - Fully responsive across mobile, tablet, and desktop viewports.

---

## Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Animations**: [Motion for React](https://motion.dev/)
- **Styling**: Vanilla CSS (Custom tokens, fluid typography via `clamp()`)
- **Icons**: [Lucide React](https://lucide.dev/)

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/sujith0718-coder/csea-saraswathi-pooja.git

# Navigate to project directory
cd csea-saraswathi-pooja

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Compile and bundle
npm run build

# Preview production build locally
npm run preview
```
